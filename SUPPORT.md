# Support

Use GitHub Discussions, when enabled, for usage and design questions. Otherwise open a GitHub
issue with the appropriate template:

https://github.com/Hyhyhyyy/train_guard/issues

Before asking, check the README, [CLI reference](docs/CLI.md),
[configuration guide](docs/CONFIGURATION.md), migration guide, existing issues, and
`train-guard --help`.
Provide the Train Guard version, Python version, operating system, command, expected behavior,
sanitized output, and a minimal synthetic configuration.

Never post credentials, private paths, hostnames, real datasets, reports, model artifacts, or
training logs. Replace them with synthetic placeholders and confirm the report still reproduces.

Bug reports are handled on a best-effort basis. This community project does not provide
guaranteed response times or private operational support. Vulnerabilities must use the private
process in [SECURITY.md](SECURITY.md).

For 0.6.0rc1 reports, state the installation method and whether the wheel, sdist, or
single-file artifact was used. TUI requests are feature requests: this candidate has no TUI
command or extra.
